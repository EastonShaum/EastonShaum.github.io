<service live="lisap.app">

LISAP

Shares streaming sign-in codes with everyone on the account. The owner's Gmail forwards the code emails, Gmail and Pub/Sub push them to a Cloudflare Worker, and Firebase Cloud Messaging puts the code on every phone within seconds. I tried Gmail polling and Twilio SMS first, then moved it from a laptop to Workers and D1 so it's always on and free to run.

Cloudflare Workers · D1 · React · Gmail API · Pub/Sub · Firebase

<pipeline runs-on="raspberry-pi-5">

ClipForge

A self-hosted pipeline for paid clipping campaigns. It records or downloads footage, transcribes it with Whisper, has Claude pick the moments worth clipping, and renders 9:16 videos with FFmpeg. A Pi runs the brain, a laptop does the heavy rendering over Tailscale, and every clip waits for my approval on my phone.

Python · FastAPI · Whisper · Claude API · FFmpeg · SQLite · Tailscale
